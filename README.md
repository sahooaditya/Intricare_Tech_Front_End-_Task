# Advance Campaign - Screenshot Conversion

Responsive HTML, CSS, and JavaScript implementation of the provided campaign workflow screenshot.

## Files

- `index.html` - Page structure and content
- `assets/css/style.css` - Responsive layout, components, light theme, and dark theme
- `assets/js/script.js` - Theme toggle, sidebar toggle, import method switching, URL validation, CSV upload state, lead list selection, and toast feedback

## Run

Open `index.html` directly in a browser, or serve the folder locally:

```

## Features

- Desktop dashboard layout matching the campaign workflow screenshot
- Responsive tablet and mobile breakpoints
- Light and dark theme with saved preference
- Collapsible mobile sidebar
- Import method cards for LinkedIn Search, CSV Upload, Lead Lists, and Inbound Webhook
- LinkedIn URL validation
- CSV drag and drop/upload state with Map Properties screen
- Lead list selection state
```
